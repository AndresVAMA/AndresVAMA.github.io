# AI Way · portafolio

Sitio estático del portafolio de **AI Way**: ciencia de datos con rigor de físico (Ciudad de México).

- Diez servicios con demo sobre datos sintéticos de verdad conocida, sus cifras contra criterio y sus límites por escrito.
- Gráficas interactivas con Plotly autoalojado; sin backend ni dependencias de build.

Todas las cifras de las demos provienen de simulaciones propias (datos ilustrativos); ningún dato es de un cliente.
